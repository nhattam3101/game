# MonsterSurvival

Unity 6.6 project (`6000.6.6f1`). Production assets are organized below
`Assets/MonsterSurvival`; imported TextMesh Pro resources remain in their
standard third-party folder.

- Scenes: `Assets/MonsterSurvival/Content/Scenes`
- Shared runtime code: `Assets/MonsterSurvival/Code/Runtime`
- Shared editor tools: `Assets/MonsterSurvival/Code/Editor`
- Feature modules: `Assets/MonsterSurvival/Features`
- Build Profiles: `Assets/MonsterSurvival/Settings/Build Profiles`

See `Assets/MonsterSurvival/README.md` for ownership and folder rules.
